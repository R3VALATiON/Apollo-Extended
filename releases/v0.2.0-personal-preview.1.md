## Changelog
- Accept and validate the versioned native-feedback traffic policy over the existing encrypted control connection.
- Acknowledge requested mode and enforce a six-second lease; stop queued native PCM traffic when disabled or when the lease expires.
- Retain the inherited native virtual DualSense and compatibility backends, adaptive triggers, rumble, LEDs, touchpad and motion support.
- Preserve pinned VIIPER / usbip-win2 / ViGEmBus dependencies and integrity checks.
- Fix installer packaging to use the bundled SudoVDA device utility; correct dependency-install script syntax.
- Add installer PowerShell syntax validation and personal testing packaging notices.

## Validation and known limits
- Native feedback policy tests, installer script syntax checks, compilation and NSIS packaging must pass before this release is published.
- Driver installation, upgrades, controller enumeration and real game behavior have not been verified on a physical Windows test system.
- Bundled third-party driver and helper requirements remain applicable; this prerelease is not a driver compatibility certification.
- End-to-end physical DualSense haptics, controller audio, adaptive triggers and automatic network adaptation remain hardware-unverified.
- Use the matching personal Artemis and Apollo previews for the new traffic-policy negotiation. Changing controller emulation can require reconnecting and restarting the game.
